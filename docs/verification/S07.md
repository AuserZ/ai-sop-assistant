## Implemented changes (concise)

- **Contracts & cryptography (`src/server/documents/contracts.ts`, `src/server/db/schema.ts`):** Added `sourceLinkTtlSeconds = 60`, `documentLibraryBounds`, `escapeIlikePattern` (`%`, `_`, `\`), microsecond-preserving base64url keyset cursor encode/decode, `listDocumentsQueryInput`, `documentSourceQueryInput`, `documentSourceContentQueryInput`, `DocumentLibraryItemDto`, `DocumentSourceDto`, HKDF-SHA256 `deriveSourceSigningKey`, `signDocumentSourceToken`, constant-time `verifyDocumentSourceToken` (`timingSafeEqual`), and RFC 5987 `formatContentDisposition`.
- **Backend service & routes (`src/server/documents/{service,http}.ts`, `src/app/api/documents/route.ts`, `src/app/api/documents/[id]/source/route.ts`, `src/app/api/documents/[id]/source/content/route.ts`):**
  - `GET /api/documents`: locks live user/session (`FOR SHARE`), enforces `sop_documents.status = 'ACTIVE'` in SQL `WHERE` and `diagnostics: null` for Staff, returns all 6 lifecycle states + batch diagnostics (`processingErrorCode`, `rejectionReason`, `latestJob`, page/chunk/issue counts, `hasPreview`) for Admin, and never exposes object keys, `sha256`, or signed URLs.
  - `GET /api/documents/[id]/source`: reauthorizes live role/status (returning identical `404 NOT_FOUND` for missing or non-`ACTIVE` Staff targets with zero existence oracle), issues a 60s signed same-origin URL `/api/documents/[id]/source/content?token=...` with genuine `page`/`section` context, and writes a sanitized `document.source_authorized` audit event omitting token/URL.
  - `GET /api/documents/[id]/source/content`: verifies HMAC token in constant time (`403 SOURCE_LINK_INVALID`, `410 SOURCE_LINK_EXPIRED`), rechecks live session (`account.id === claims.accountId`, else `403 FORBIDDEN`) + live DB `status = 'ACTIVE'` (for non-Admin) and `sha256` (`404 NOT_FOUND`), reads private storage with 30s timeout and byte/SHA-256 verification, and serves original bytes with hardened headers (`Cache-Control: private, no-store`, `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Cross-Origin-Resource-Policy: same-origin`, `Referrer-Policy: no-referrer`). Preserved `GET /api/documents/[id]` unchanged for Admin upload polling.
- **Responsive UI (`src/components/documents/{library-panel.tsx,upload-panel.tsx,client.ts}`, `src/app/documents/page.tsx`, `docs/api-contracts.md`):** Searchable SOP library in `List Document SOP` (`/documents`) for Staff and Admin with keyboard search (`Enter`/button), clear/refresh, keyset pagination, `Open original` (inline) & `Download original` (attachment) with `page`/`section` context, Admin diagnostics and `Review and verify` links, `min-h-11` targets, `320px` overflow-free layout, and 3-menu cap preserved.
- **Automated tests (`tests/unit/library.test.ts`, `tests/integration/library.test.ts`, `tests/e2e/library.spec.ts`):** Added 7 unit tests, 3 comprehensive PostgreSQL integration tests, and full Playwright E2E coverage.
