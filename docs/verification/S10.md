## Implemented changes (concise)

- **Contracts & fail-closed model config (`src/server/answers/{contracts,config,index}.ts`):** Defined PRD Section 7 discriminated outcomes (`SupportedAnswer`, `NoEvidenceAnswer` with exact `"No SOP found for this question"` + `sources: []`, and `ChatServiceFailure` with safe static messages and zero SOP/draft leakage), strict private generator/judge Zod schemas, and 6-stage timings (`retrievalMs`, `generateMs`, `deterministicCheckMs`, `judgeMs`, `citationResolveMs`, `totalMs`). Live `openai` mode requires explicit `OPENAI_ANSWER_MODEL`, `OPENAI_JUDGE_MODEL`, and `OPENAI_API_KEY`, rejecting unverified ADR 23 placeholder patterns; fixture mode and `OPENAI_BASE_URL` overrides are strictly loopback-gated.
- **Private structured generator & deterministic validator (`src/server/answers/{generator,deterministic}.ts`):**
  - Generator accepts ONLY `{ question, passages }` (never history, prior answers, or summaries), fences untrusted inputs with `<` escaped as `\u003c`, separates `response.text()` read aborts (`503`) from `JSON.parse()`/Zod failures (`502`), and provides a deterministic injection-immune `synthetic_fixture` extractor.
  - Deterministic validator checks non-empty schema, strict chunk membership/dedup, zero LLM-authored URLs or injection leaks, sequential procedural numbering & per-document source order (`lastAnchorByDocument`), exact numbers/decimals/unary signs/comparators (`<`, `<=`, `>`, `>=`, `±`)/post-numeric `minimum`/`maximum`/units (incl. `µL`/`µg`/`rpm`/`mbar`/`mmHg`), compound & non-numeric safety conditions (`if`/`until`/`unless`), named table row-key bindings, and substantive lexical grounding.
- **Independent claim-level LLM judge, live citation resolver & service (`src/server/answers/{judge,citations,service}.ts`):**
  - Separate judge invocation (`OPENAI_JUDGE_MODEL`, zero generator prompt/history leakage) enforcing complete pigeonhole coverage across claim indices `0..N-1`; fails closed on `FAIL`/`UNCERTAIN`/disagreement (`ANSWER_JUDGE_REJECTED`) or provider/schema errors (`JUDGE_*`), never releasing candidate text and never masquerading as `No SOP found for this question`.
  - `resolveVerifiedCitations` re-queries PostgreSQL via S09's `loadOriginalActivePassagesByIds` on exact `SnapshotIdentity` right before answer release (failing closed on partial or full revocation to `SOURCE_ELIGIBILITY_REVOKED`), builds backend-derived `sourcePath`, preserves PDF `pageStart`/`pageEnd`, and omits `pageStart`/`pageEnd` on DOCX (`null`).
  - `generateValidatedSopAnswerForAccount` enforces pre- and post-validation `lockCurrentUser` (`401 UNAUTHENTICATED` on deactivated accounts).
- **Tier A 50-question benchmark & tests (`docs/benchmarks/rag-benchmark-rubric.md`, `tests/unit/{answers,answer-benchmark}.test.ts`, `tests/integration/answers.test.ts`):** Added 14 unit tests, a 50-case Tier A synthetic benchmark runner (`50/50` correct, `34/34` `100%` valid citations, `0` invented steps, `16/16` exact fallback; p50 `totalMs=3.23 ms`, p95 `15.58 ms` in-process synthetic), and a real PostgreSQL + pgvector integration suite for PDF/DOCX citations, trap exclusion, mid-flight delete revocation, and account deactivation.
