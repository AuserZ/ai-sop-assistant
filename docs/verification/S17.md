## Implemented changes (concise)

- **Schema & migration:** Added nullable `archived_at`, partial active-owner index `chat_conversations_owner_active_updated`, DB triggers (`enforce_chat_conversation_archive` blocking un-archive/title edits on archived threads; updated `enforce_chat_message_owner` blocking new `user` turns on archived threads), and least-privilege `GRANT UPDATE (archived_at)` for `sop_runtime` in `src/server/db/schema.ts`, `drizzle/0008_chat_conversation_archive.sql`, `drizzle/meta/0008_snapshot.json`, and `drizzle/meta/_journal.json`.
- **Backend chat contracts, service, stream & HTTP:**
  - `src/server/chat/contracts.ts`: Opaque base64url microsecond keyset cursor codec with strict calendar-date validation (`QA-S17-01`), `renameChatConversationInput`, `chatRateLimits.mutate`, pagination/rename/archive DTOs, and `activeJobId` on conversation detail.
  - `src/server/chat/service.ts`: `listOwnedConversations` keyset pagination (`limit + 1`) + escaped `ILIKE` title search filtering `archived_at IS NULL`; `getOwnedConversation` returning `activeJobId` for in-flight `QUEUED`/`RUNNING` turns; `renameOwnedConversation` & `archiveOwnedConversation` with owner isolation (`404`), active-account lock (`401`), and redacted `audit_events`/`pino` logs; `createChatTurn` archived-thread guards + concurrent race cleanup (`QA-S17-05`).
  - `src/server/chat/stream.ts`: `withOwnedChatEvents` verifies conversation is owned and `archived_at IS NULL` before streaming/replaying SSE frames.
  - `src/server/chat/http.ts` & `src/app/api/chat/conversations/[id]/route.ts`: Extended `GET /api/chat/conversations` (`limit`, `cursor`, `q`) and added `PATCH` (rename) & `DELETE` (soft-archive) handlers with `requireMutationOrigin`, rate limiting, 16 KB body cap, and `Cache-Control: private, no-store`.
- **Chat UI (Clinical Precision, strictly 3 primary menus):**
  - `src/components/chat/client.ts`: Zod schemas + `fetchConversations`, `renameConversation`, `archiveConversation`, and `resumeChatJobStream`.
  - `src/components/chat/conversation-history-panel.tsx`: Collapsible desktop rail (`lg:w-64`) + accessible mobile slide-over drawer (`role="dialog"`, `aria-modal="true"`, Escape & focus handling, `<button>` items only so primary `<nav>` links stay `<= 3`, `min-h-11` targets, search, `Load more`, inline rename, two-step soft-archive confirm).
  - `src/components/chat/chat-workspace.tsx`: Race-safe thread switching (`AbortController` + selection sequence + `conversationIdRef`), composer lock while loading history, live list upsert on send/completion, active-job SSE resume on reopen, and state reset on sign-out.
- **Tests:** Added unit coverage in `tests/unit/chat.test.ts` (and updated migration-head expectations in `tests/unit/backup-recovery.test.ts` & `tests/unit/deploy-rollback.test.ts`), PostgreSQL integration tests in `tests/integration/chat.test.ts`, and Playwright E2E test in `tests/e2e/chat.spec.ts`.
