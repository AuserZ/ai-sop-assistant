## Implemented changes (concise)

- **Storage fixture (`infra/storage-fixture/{gateway.mjs,gateway.test.mjs,verify-native.mjs}`):** Allowed server-side SigV4 `DELETE` (`AWS4-HMAC-SHA256`), rejected browser `Origin` or unsigned `DELETE` with `403`, added native `DeleteObjectCommand` + idempotency checks.
- **Database & triggers (`drizzle/0006_document_deletion.sql`, `drizzle/meta/0006_snapshot.json`, `drizzle/meta/_journal.json`, `src/server/db/schema.ts`):** Added `'DELETED'` status, `deleted_by`, `deleted_at`, `cleanup_*` columns, `sop_documents_deletion_binding` CHECK, `sop_documents_cleanup_due` index, updated `app.enforce_sop_document_activation()` (`ACTIVE -> DELETED` only by active Admin; `DELETED` tombstones irreversible), added `app.block_deleted_document_artifacts()` (`23514` on `sop_chunks`, `sop_extraction_pages`, `sop_verification_issues`, `sop_verification_records`), and granted `UPDATE` on deletion/cleanup columns to `sop_runtime` while preserving `42501` immutability on original metadata.
- **Backend, durable reconciler & race guards (`src/server/documents/{storage,contracts,http,service}.ts`, `src/app/api/documents/[id]/route.ts`, `src/server/auth/http.ts`, `src/server/verification/service.ts`, `src/server/ingestion/service.ts`, `src/server/jobs/dispatch.ts`):**
  - `DELETE /api/documents/[id]` (CSRF origin check allowing bodyless `DELETE`, active Admin, rate limits) atomically commits `DELETED` tombstone, fails non-terminal `workflow_jobs` (`DOCUMENT_DELETED`), writes `document.deleted` audit event, and triggers `reconcileDocumentDeletions()` (also wired into `startWorkflowDispatcher()`).
  - `reconcileDocumentDeletions()` uses `FOR UPDATE SKIP LOCKED` + 45s lease token, deletes `sop_chunks`/`sop_extraction_pages`/`sop_verification_issues` first, deletes private S3/R2 objects (`originalKey`, `previewKey`, `stagingKey`), retries storage failures with exponential backoff (`min(2^attempts, 60)`s), and audits completion/failure.
  - Added `queryEligibleActiveChunks()` and `resolveDocumentCitationAvailability()` (`UNAVAILABLE` for Staff, `DELETED` for Admin); blocked `DELETED` docs across `/source`, `/source/content`, `/preview` (`404`), and verification/ingestion (`409 DOCUMENT_DELETED`).
- **Admin UI, docs & tests (`src/components/documents/{client.ts,library-panel.tsx,upload-panel.tsx}`, `src/components/verification/{client.ts,review-workspace.tsx}`, `docs/api-contracts.md`, `docs/database.md`, `tests/{unit,integration,e2e}/deletion.*`):** Added Admin `"Delete SOP"` inline confirmation with backup-retention notice, `DELETED` badge + `Cleanup: <STATE>` polling + `"Retry cleanup"`, zero Staff delete controls, and unit/DB/Playwright tests.
