## Implemented

- Next.js App Router with TypeScript and Tailwind, a minimal home page, and liveness and readiness routes. Readiness checks the database and vector operator and sends a generic HTTP 503 if they are unavailable.
- PostgreSQL bootstrap and Drizzle migration with separate runtime, migrator and n8n operational identities. The app role can append and read audit events. The n8n operational role cannot connect to the application database.
- Local Compose configuration with a loopback app port, internal database network, file-based credentials and an optional network-isolated LibreOffice helper. GitHub Actions defines the clean install, PRD integrity, lint, type, build, unit, database and container smoke checks.

The main files are the runtime under `src/`, dependency and tooling configuration at the project root, `drizzle/`, `infra/`, `docker-compose.yml`, `Dockerfile`, `scripts/local-secrets.mjs`, `tests/` and `.github/workflows/ci.yml`. Local instructions and database ownership are documented in the supporting guides. [Local runtime](../deployment.md) · [Database](../database.md) · [CI workflow](../../.github/workflows/ci.yml)
