## Implemented changes (concise)

- **Admin directory & access mutations (`src/server/auth/{validation,rate-limit,accounts,invitations}.ts`, `src/app/api/users/route.ts`, `src/app/api/users/[id]/route.ts`):**
  - `GET /api/users`: enforces live active Admin session (`lockCurrentAdmin`), rate limits (`users-global`, `users:list`), duplicate query-param rejection, escaped `ILIKE` search (`q`), `role` (`ADMIN`/`STAFF`), `status` (`ACTIVE`/`INACTIVE`), `limit` (`1..100`, default `50`), deterministic ordering (`createdAt DESC, id ASC`), summary counts, and sanitized `pendingInvitations` (never exposing `tokenDigest`).
  - `POST /api/users/invite`: added transactional duplicate active pending invitation guard (`409 INVITATION_ALREADY_PENDING`) while permitting re-invitation after expiry or revocation; writes redacted `audit_events` metadata (`{ role }` only — zero emails, tokens, or passwords).
  - `PATCH /api/users/[id]`: enforces `requireMutationOrigin` (CSRF + `application/json` + 4 KB cap), rate limits (`users-global`, `users:update`), deadlock-free `FOR UPDATE` locking on `[actor.id, targetId]`, self-lockout protection (`409 SELF_ACCESS_CHANGE_DENIED`), last-active-Admin protection (`409 LAST_ADMIN_REQUIRED`), immediate `auth_sessions` deletion + DB trigger revocation, redacted `account_access_changed` audit event, and `{ user }` response DTO.
- **Admin UI, 3-menu navigation, docs & tests (`src/app/users/page.tsx`, `src/components/users/{client.ts,user-management-panel.tsx}`, `src/components/auth/session-status.tsx`, `docs/{api-contracts,authentication}.md`, `tests/{unit,integration,e2e}/users.*`):**
  - Added `/users` Admin User Management UI (`320px` overflow-free, `min-h-11` targets, summary badges, passwordless invite form, pending invitations list, search/role/status filter bar with `data-testid="users-count-status"`, role toggle, deactivate/reactivate, disabled self-row actions, and Staff `role="alert"` `"Admin access required."`).
  - Completed the 3-menu navigation in `session-status.tsx` (`Chat`, `List Document SOP`, `User Management` for `ADMIN`; `Chat` and `List Document SOP` for `STAFF`).
  - Added `tests/unit/users.test.ts` (`5/5`), `tests/integration/users.test.ts` (real PG directory, duplicate/expired/revoked/accepted invites, RBAC/CSRF/self/last-Admin, and mid-session deactivation revoking ongoing session, chat SSE stream, chat message submission, and 60s signed SOP source download), and `tests/e2e/users.spec.ts`.
